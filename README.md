# computacao-grafica-opencv
Trabalho de Computação Gráfica desenvolvido em Python utilizando a biblioteca OpenCV


# 1º TDE – Computação Gráfica

Repositório desenvolvido para apresentar as atividades do 1º TDE da disciplina de Computação Gráfica, do curso de Sistemas de Informação do Centro Universitário Santa Terezinha (CEST).

O trabalho aborda conceitos teóricos de Computação Gráfica e atividades práticas de processamento digital de imagens utilizando Python e a biblioteca OpenCV.

## Objetivo do Trabalho

Compreender os principais conceitos da Computação Gráfica e aplicar técnicas de processamento de imagens, utilizando a linguagem Python para realizar operações de conversão, redimensionamento, suavização, binarização, detecção de contornos e análise de objetos.

## Tecnologias Utilizadas

- Python
- OpenCV (cv2)
- Visual Studio Code

## Atividades Desenvolvidas

### Parte Teórica

**Questão 1 – Conceitos de Computação Gráfica**
Estudo dos conceitos, aplicações e utilização da Computação Gráfica.

**Questão 2 – Áreas da Computação Gráfica**
Estudo das áreas de modelagem e análise de imagens.

**Questão 3 – Bitmap e Vetorial**
Diferenças entre imagens bitmap, formadas por pixels, e imagens vetoriais, representadas por elementos matemáticos.

**Questão 4 – Transformações Geométricas**
Estudo das transformações de translação, rotação e escala.

### Parte Prática – Python e OpenCV

**Questão 5 – Conversão para Escala de Cinza**
Carregamento de uma imagem colorida e conversão para escala de cinza, apresentando os resultados.

**Questão 6 – Redimensionamento de Imagens**
Criação de versões da imagem com 50%, 25% e dimensões personalizadas pelo usuário.

**Questão 7 – Suavização de Imagens**
Aplicação de filtros Blur com kernels 3x3, 5x5 e 9x9 para comparar os efeitos da suavização.

**Questão 8 – Binarização com Threshold**
Aplicação de diferentes valores de threshold (80, 120 e 180) para analisar a separação entre objetos e fundo.

**Questão 9 – Detecção e Contagem de Objetos**
Identificação de contornos, contagem de objetos e apresentação dos resultados utilizando OpenCV.

**Questão 10 – Cálculo da Área dos Objetos**
Cálculo das áreas dos objetos detectados, filtragem de objetos pequenos e apresentação da maior área, menor área e área total dos objetos válidos.

## Arquivos e Materiais

O repositório contém os códigos-fonte em Python, as imagens utilizadas nas atividades e as imagens resultantes do processamento, permitindo visualizar e comparar os resultados obtidos.

## Conclusão

A realização deste trabalho permitiu aplicar na prática os conceitos estudados na disciplina de Computação Gráfica, desenvolvendo conhecimentos sobre processamento digital de imagens e utilizando o OpenCV para realizar análises e operações com imagens.
