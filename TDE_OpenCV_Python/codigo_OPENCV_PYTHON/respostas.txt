QUESTÃO 3 – Bitmap e Vetorial

Resposta: C.

Explicação:

As imagens vetoriais são representadas por elementos matemáticos, como linhas, curvas e formas geométricas. Por isso, podem ser ampliadas ou reduzidas sem perda significativa de qualidade.

As imagens bitmap são formadas por pixels. Quando uma imagem bitmap é ampliada excessivamente, os pixels podem ficar visíveis e a imagem pode perder qualidade.

Portanto, a alternativa C está correta.

*QUESTÃO 7 – Análise de suavização

Objetivo:

Analisar o efeito da suavização de uma imagem utilizando a função blur() com diferentes tamanhos de kernel.

Desenvolvimento:

1. A imagem foi carregada utilizando OpenCV.
2. Foi aplicado um filtro blur com kernel 3x3.
3. Foi aplicado um filtro blur com kernel 5x5.
4. Foi aplicado um filtro blur com kernel 9x9.
5. A imagem original e os três resultados foram apresentados para comparação.

Conclusão:

O tamanho do kernel influencia diretamente na intensidade da suavização. O kernel 3x3 produz uma suavização menor, enquanto o 5x5 apresenta uma suavização intermediária. O kernel 9x9 produz uma suavização maior, reduzindo mais detalhes e deixando as bordas menos definidas.

Arquivo utilizado: questao7.py
